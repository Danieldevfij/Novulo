# Novulo expressies

This repository contains examples of Novulo expressions and a small Python
chatbot that can suggest expressions based on a description of your goal.

## Running the chatbot

Execute the script using Python 3:

```bash
python3 novulo_chatbot.py
```

The bot will prompt for a description of the goal you want to achieve. It then
returns the expression from its database that most closely matches your input.
Type `exit` to quit the chat.
